Модель → планировка из каталога → допы → доставка/сборка → ориентировочная цена «от» → заявка.
Кабинет мастера: `#/admin`, PIN 1234 (заявки со статусами и комментарием клиенту + редактор прайса).

Цены: каталог vk.com/@bany35rf-katalog («актуальны на 6 ноября»). `price: null` — «цена по запросу», в сумму не входит.
Хранилище демо: IndexedDB `banka-demo`, ключи localStorage с префиксом `banka-demo:`, кэш SW `banka-v1`.
